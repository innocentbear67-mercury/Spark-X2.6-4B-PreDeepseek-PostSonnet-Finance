# private_markets_pe — build notes

Profile A, 1000 rows. Registries: 20 fictional PE funds (vintage, commitment, fee, carry, hurdle, term) and 23 fictional portfolio companies (sector, fiscal-year end, currency).
Authored seed families (46 shapes): XIRR from dated flows (net, write-off, delay, gross); MOIC/DPI/RVPI/TVPI; European waterfall carry, LP proceeds, catch-up tier, GP profit share; American deal-by-deal carry; LBO leverage, equity cheque, interest, coverage, exit EV, exit equity, MOIC, exit leverage; J-curve fee drag and NAV path; subscription-line interest, fee offset, net fee, all-in cost; schedule and term-sheet extraction; LP-right, covenant, stage and waterfall-type labels; nine summary families; 60 definitional and 140 table-grounded QA; 12 tool families including wrong-argument recovery and missing-NAV abstention.
IRR is solved by bisection on actual/365 discounting inside generate.py, so every percentage answer reproduces from the table alone. Every numeric ground truth is computed from the same fixture values rendered into context; none is typed by hand.
Splits are assigned per fixture key in sha256 order inside each task stratum: 798 train / 100 val / 102 test, every task at least 10 rows per split. No masked question or context+question pair crosses splits.
Known weaknesses: partial catch-up fixtures leave the GP with well under 20 percent of profit (arithmetically right, easy to misread); LBO fixtures use one fixed five-year hold, so no path dependency or covenant step-down; equity cheques ignore rollover and closing adjustments; term sheets are generic rather than negotiated documents.
Coverage gaps: no secondaries pricing, continuation-fund economics, PIK or covenant step-downs, fund-of-funds look-through, or FX effects on realised returns.
